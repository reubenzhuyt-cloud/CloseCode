# Protocol / HttpApi

> last-verified: bf24a67263 @ 2026-11-24

## Responsibility
Defines the V2 HTTP contract as an Effect `HttpApi`: which groups exist, what middleware wraps them, and how concrete service identities are injected. Owns placement/typing of the API; it does **not** implement handlers (Server does) and does not perform I/O.

## Key Paths
- `packages/protocol/src/api.ts` — `makeApi`, `makeDefaultApi`, `Api` type, `LocationGroups`/`SessionGroups`/`MixedMiddlewareGroups` composition; `ExperimentalGroup` is composed in `groups/experimental.ts`
- `packages/protocol/src/groups/` — one group per resource: `agent`, `artifact`, `automation`, `blob`, `command`, `config`, `credential`, `debug`, `event`, `experimental`, `form`, `fs`, `generate`, `integration`, `job`, `location`, `machine`, `mcp`, `media`, `message`, `migration`, `model`, `permission`, `persistent-pty`, `plugin`, `project`, `provider`, `pty`, `reference`, `rpc`, `server`, `session`, `shell`, `skill`, `usage`, `vcs`, `voice`, `websearch`, `worktree`
- `packages/protocol/src/groups/experimental.ts` — `ExperimentalGroup` = `PersistentPtyGroup` + media/blob get + automation, artifact, job, machine endpoints
- `packages/protocol/src/middleware/` — `authorization.ts`, `schema-error.ts`
- `packages/protocol/src/errors.ts` — shared protocol errors (`InvalidRequestError`, `SessionNotFoundError`, `AutomationNotFoundError`, `VideoNotFoundError`, `BlobNotFoundError`, `MachineNotFoundError`, …)
- `packages/protocol/openapi.json` — generated OpenAPI document (regenerated by the client codegen; 147 paths / 179 operations at the stamp commit)
- `packages/protocol/src/simulation.ts` — simulation-specific API extension

## Public API / Key Types
- `makeApi({ definitions, locationMiddleware, formLocationMiddleware, sessionLocationMiddleware })` — binds Event group + middleware keys
- `makeDefaultApi(...)` — same with the default `EventGroup`
- `Api<...>` — parameterized HttpApi type; middleware placement is owned by Protocol while Server injects concrete keys
- Group makers: `makeSessionGroup`, `makePermissionGroup`, `makeFormGroup`, `makeLocationGroup`, `makeEventGroup`
- `server.skill` group (`groups/skill.ts`): `skill.list` (`GET /api/skill`) plus read-only `skill.diagnostic` (`GET /api/skill/diagnostic`, query `LocationQuery` + required `agent: Agent.ID`, success `Skill.Diagnostic`, errors `AgentNotFoundError`/`ServiceUnavailableError`)
- `experimental.generate.video.create|get` — submit a video job / read it (`VideoRunning` | `VideoCompleted` | `VideoError`); jobs outlive the request
- `experimental.blob.get` — immutable blob by ID, streams with ETag/Range
- `experimental.automation.*` — create/list/get/pause/resume/remove automations (removed `schedule` group replaced it; `packages/schema/src/schedule.ts` is gone)
- `experimental.machine.list|add|remove|link` — machine management plus the raw WebSocket link at `/api/experimental/machine/link`
- Experimental convention: new endpoints live under `/api/experimental/<group>` with `experimental.<group>.<method>` identifiers, enforced both directions by `packages/protocol/test/experimental-identifiers.test.ts`; the client namespaces them `client.experimental.*` by URL (`client.ts:74`); experimental fields on stable endpoints go under an `experimental` key (AGENTS.md "Experimental API")

## Dependencies
- In: `schema` (event/session/config shapes), `effect/unstable/httpapi`.
- Out: `client` (derives `ClientApi`), `server` (implements groups), `plugin`.
