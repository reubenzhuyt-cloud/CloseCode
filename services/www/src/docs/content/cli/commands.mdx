title: "Commands"
description: "Reference for the closecode command line."

Every command accepts `--help` for its full flag list, for example `closecode run --help`. Commands that talk to a server also accept `--standalone` to run a private server and `--server <url>` to target a specific one.

## run

Sends a message and prints the reply without opening the interactive interface.

```bash
$ closecode run "Explain this repository"
```

### CI

In CI, pass a provider API key as a secret and use standalone mode so the private server receives it. For example, this GitHub Actions job reviews the checked-out repository:

```yaml
name: OpenCode review
on: [pull_request]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: oven-sh/setup-bun@v2
      - run: git clone --depth 1 https://github.com/reubenzhuyt-cloud/CloseCode /tmp/CloseCode
      - run: bun install --cwd /tmp/CloseCode
      - run: bun run --cwd /tmp/CloseCode/packages/cli build --single
      - run: echo "/tmp/CloseCode/packages/cli/dist/cli-linux-x64/bin" >> $GITHUB_PATH
      - run: closecode run --standalone --model anthropic/claude-sonnet-4-5 "Review this repository for correctness and summarize any issues."
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
```

Choose a model.

```bash
$ closecode run --model anthropic/claude-sonnet-4-5 "Refactor parseToken"
```

Continue the last session.

```bash
$ closecode run --continue "Now handle the expired case"
```

Emit newline-delimited JSON for scripts.

```bash
$ closecode run --format json "List the TODO comments"
```

Attach files to the message.

```bash
$ closecode run --file src/server.ts --file src/client.ts "Review these for bugs"
```

Run with a specific agent.

```bash
$ closecode run --agent build "Fix the failing test"
```

View all subcommands and flags.

```bash
$ closecode run --help
```

```bash
$ closecode mini
```

Continue the last session.

```bash
$ closecode mini --continue
```

Start with a model and an initial prompt.

```bash
$ closecode mini --model anthropic/claude-sonnet-4-5 --prompt "Summarize this repository"
```

View all subcommands and flags.

```bash
$ closecode mini --help
```

## session

Manages sessions.

```bash
$ closecode session list
```

Limit the list and print JSON.

```bash
$ closecode session list --max-count 20 --format json
```

Delete a session and its child sessions.

```bash
$ closecode session delete ses_9c1b08
```

Export session data as JSON.

```bash
$ closecode session export ses_4f2a1c
```

Redact sensitive transcript and file data when exporting.

```bash
$ closecode session export ses_4f2a1c --sanitize
```

Import session data from a JSON file or URL.

```bash
$ closecode session import session.json
```

Import into a specific directory.

```bash
$ closecode session import session.json --directory ~/code/project
```

View all subcommands and flags.

```bash
$ closecode session --help
```

## auth

Manages AI providers and credentials.

```bash
$ closecode auth list
```

List them as JSON.

```bash
$ closecode auth list --format json
```

Log in to a provider.

```bash
$ closecode auth login anthropic
```

Log in with a specific authentication method.

```bash
$ closecode auth login anthropic --method api-key
```

Log out of a saved account.

```bash
$ closecode auth logout anthropic work
```

Switch the active account for an integration.

```bash
$ closecode auth switch anthropic work
```

View all subcommands and flags.

```bash
$ closecode auth --help
```

## mcp

Manages MCP (Model Context Protocol) servers.

```bash
$ closecode mcp list
```

Add a remote server.

```bash
$ closecode mcp add context7 --url https://mcp.context7.com/mcp
```

Add a local server to the global config.

```bash
$ closecode mcp add everything --global -- npx -y @modelcontextprotocol/server-everything
```

Add a local server with an environment variable.

```bash
$ closecode mcp add everything --env LOG_LEVEL=debug -- npx -y @modelcontextprotocol/server-everything
```

Add a remote server with a header.

```bash
$ closecode mcp add context7 --url https://mcp.context7.com/mcp --header CONTEXT7_API_KEY=secret
```

Authenticate with an OAuth-capable remote server.

```bash
$ closecode mcp auth sentry
```

Remove stored OAuth credentials for a server.

```bash
$ closecode mcp logout sentry
```

View all subcommands and flags.

```bash
$ closecode mcp --help
```

## plugin

Manages plugins.

```bash
$ closecode plugin list
```

Include built-in server plugins.

```bash
$ closecode plugin list --builtin
```

Install a plugin and add it to the global configuration.

```bash
$ closecode plugin add @example/opencode-tui
```

Check package plugins for updates.

```bash
$ closecode plugin check
```

Update package plugins.

```bash
$ closecode plugin update
```

Remove a plugin from global configuration.

```bash
$ closecode plugin remove @example/opencode-tui
```

View all subcommands and flags.

```bash
$ closecode plugin --help
```

## serve

Starts the API and web server. See [Web](/cli/web).

```bash
$ closecode serve
```

Bind to all interfaces on a fixed port.

```bash
$ closecode serve --hostname 0.0.0.0 --port 4096
```

Allow a browser client from another origin.

```bash
$ closecode serve --cors https://app.example.com
```

View all subcommands and flags.

```bash
$ closecode serve --help
```

## pair

Shows server pairing information, including URLs, credentials, and a QR code. The
QR code contains a direct link to the advertised server, with credentials in the
URL fragment.

```bash
$ closecode pair
```

Advertise an external URL in the QR code and link.

```bash
$ closecode pair --url https://dev.example.com
```

View all subcommands and flags.

```bash
$ closecode pair --help
```

## service

Manages the background server. See [Web](/cli/web).

```bash
$ closecode service start
```

Restart it.

```bash
$ closecode service restart
```

Show its status.

```bash
$ closecode service status
```

Stop it.

```bash
$ closecode service stop
```

Read a setting.

```bash
$ closecode service get hostname
```

Set a setting.

```bash
$ closecode service set hostname 0.0.0.0
```

Allow an extra CORS origin.

```bash
$ closecode service set cors https://app.example.com
```

Pass an environment variable to the server process.

```bash
$ closecode service set env OPENCODE_LOG_LEVEL DEBUG
```

Reset a setting to its default.

```bash
$ closecode service unset hostname
```

View all subcommands and flags.

```bash
$ closecode service --help
```

## reload

Reloads configuration without restarting the server. Running sessions continue with fresh services at the next step boundary.

```bash
$ closecode reload
```

## api

Makes a request to the running server.

```bash
$ closecode api GET /api/session
```

Call an operation ID with a query parameter.

```bash
$ closecode api v2.session.list --param limit=10
```

Send a JSON body.

```bash
$ closecode api v2.session.create --data '{"title": "New session"}'
```

Add a request header.

```bash
$ closecode api GET /api/session -H "accept: application/json"
```

View all subcommands and flags.

```bash
$ closecode api --help
```

## upgrade

Upgrades OpenCode to the latest or a specific version. Alias: `update`.

```bash
$ closecode upgrade
```

Upgrade to a specific version with a specific package manager.

```bash
$ closecode upgrade 1.18.15 --method bun
```

View all subcommands and flags.

```bash
$ closecode upgrade --help
```

## uninstall

Removes OpenCode and all related files.

```bash
$ closecode uninstall
```

Preview what would be removed.

```bash
$ closecode uninstall --dry-run
```

Keep configuration and session data.

```bash
$ closecode uninstall --keep-config --keep-data
```

View all subcommands and flags.

```bash
$ closecode uninstall --help
```
